# Member UI/UX implementation plan

Branch: `codex/member-ui-ux-improvements`
Scope: member-facing presentation, accessibility and shared components only. No server function, RLS, Supabase, booking, payment, promotion, entitlement, analytics, route or deployment changes.

## Shared root causes confirmed

1. **Foundation drift** — semantic tokens and component rules are split between token, base, member and override styles (P2-04).
2. **Interaction-accessibility gap** — focus and the custom language menu do not fully meet the required keyboard contract (P1-03, P2-01, AX-01/02).
3. **Critical information clipping** — a generic `truncate` treatment hides booking location (P1-04, AX-03).
4. **Localized fallback drift** — local payment/error code bypasses the shared locale system (P1-05, AX-04).
5. **Completion-flow changes requiring product approval** — checkout draft restoration and subscription cancellation confirmation add state/steps (P1-01, P1-02). They are isolated below and will not be implemented silently.
